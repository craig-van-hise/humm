# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The Humm application currently uses hardcoded Tone.js synth parameters for its audio engine (Sawtooth + 500Hz filter for the root drone, Triangle + 600Hz filter for the 5th drone, and Triangle for the guide melody). 

**Objective:** Introduce dynamic user controls for these acoustic properties. A new settings cog will be added to the header of the `AudioControls` component, triggering a `ToneSettingsModal`. The selected waveform and filter frequency parameters must persist via LocalStorage and dynamically update the running Tone.js engine without requiring a session restart.

## 2. Technical Decisions & Dependencies
*   **State Management:** Five new persistent state variables will be introduced in `App.tsx` via `usePersistentState`: `droneRootWaveform`, `droneRootFilterFreq`, `droneFifthWaveform`, `droneFifthFilterFreq`, and `guideWaveform`.
*   **Tone.js Dynamic Updates:** Standard Tone.js property setters (`.set({ type: newType })` for oscillators and `.frequency.rampTo(newFreq, 0.1)` for filters) will be utilized inside a new `useEffect` block in `useAudioEngine.ts` to ensure seamless audio transitions during live playback.
*   **Component Architecture:** A new file, `src/components/ToneSettingsModal.tsx`, will handle the UI for these selections (dropdowns for waveforms, sliders for frequencies).

    3.  In `initEngine`, replace the hardcoded oscillator types and filter frequencies with these new props.
    4.  Add a new `useEffect` block to handle dynamic updates while the engine is running:
        ```typescript
        useEffect(() => {
          if (!isEngineInit.current) return;
          
          if (droneRootOscRef.current) droneRootOscRef.current.set({ type: droneRootWaveform });
          if (droneRootFilterRef.current) droneRootFilterRef.current.frequency.rampTo(droneRootFilterFreq, 0.1);
          
          if (droneFifthOscRef.current) droneFifthOscRef.current.set({ type: droneFifthWaveform });
          if (droneFifthFilterRef.current) droneFifthFilterRef.current.frequency.rampTo(droneFifthFilterFreq, 0.1);
          
          if (guideSynthRef.current) guideSynthRef.current.set({ oscillator: { type: guideWaveform } });
        }, [droneRootWaveform, droneRootFilterFreq, droneFifthWaveform, droneFifthFilterFreq, guideWaveform]);
        ```
