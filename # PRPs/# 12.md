# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
Real-time adjustments to the Acoustic Tone Mixer and Tone Settings Modal are causing audio dropouts and sequence interruptions. This is caused by React dependency thrashing: state updates re-create the `initEngine`, `startDrone`, and `playGuidePitch` function identities, which in turn causes the `isSessionActive` lifecycle `useEffect` to re-run and re-trigger Tone.js `.start()` methods mid-playback.

**Objective:** Stabilize the `useAudioEngine` hook by completely removing React state variables from the `useCallback` dependency arrays. We will use a "Latest State Ref" pattern to allow stable callback functions to access current state without triggering React re-renders in the audio lifecycle.

## 2. Technical Decisions & Dependencies
*   **Latest State Ref Pattern:** A `useRef` (`activeStateRef`) will continuously track `rootNote` and `droneOctaveOffset`. The callback functions will read from this ref instead of the React state closures.
*   **Zero-Dependency Callbacks:** `initEngine`, `startDrone`, `stopDrone`, `stopAllAudio`, and `playGuidePitch` will have empty `[]` (or perfectly stable) dependency arrays.
*   **Isolated Mutation Effects:** The `useEffect` blocks responsible for `.rampTo()` and `.type =` mutations will be the *only* parts of the hook that depend on the dynamic state variables.
