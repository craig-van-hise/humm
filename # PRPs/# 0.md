**Project Name:** Humm (Resonance Hum Mobile Web App)  
**Status:** In Progress / Active

**Tech Stack:** React 18, TypeScript, Vite, Tailwind CSS v3, Tone.js, Framer Motion, Lucide Icons

## 1. Executive Summary & Core Objectives

**Humm** is a minimalist, mobile-first web application designed to pair the physiological and neurological benefits of therapeutic humming (vagal nerve stimulation, sinus nitric oxide release, parasympathetic nervous system activation) with gentle, reference-guided pitch sequences.

The application serves two synchronized functions:
1. **Guided Breathwork Pacer:** Visual breath ring pacing users through configurable **Inhale $\rightarrow$ Hum $\rightarrow$ Rest** timing cycles.
2. **Interactive Pitch & Drone Audio Engine:** Real-time Web Audio synthesis featuring a warm background drone (Root + 5th) paired with monophonic guide tone melodies (2–5 note intervals) played over an interactive 17-key visual piano keyboard.

## 2. Technical Architecture & Audio Engine Design

```text
                                  ┌───────────────────────────────┐
                                  │      Tone.OmniOscillator      │
                                  │   (Lowpass Filtered <400Hz)   │
                                  │      Root + 5th Drone Synth   │
                                  └───────────────┬───────────────┘
                                                  │
                                                  ▼
┌──────────────────┐    ┌─────────────────┐ ┌──────────┐    ┌──────────────────┐
│  User Tap / Touch│───►│ Tone.start()    │─┤ Tone.Gain├─►  │ Tone.Destination │
│  (iOS Unlock)    │    │ (Context Awake) │ └──────────┘    │ (Mobile Speaker) │
└──────────────────┘    └─────────────────┘ ┌──────────┐    └──────────────────┘
                                            │ Tone.Gain├─►           ▲
                                            └─────▲────┘             │
                                                  │                  │
                                  ┌───────────────┴───────────────┐  │
                                  │          Tone.Synth           │──┘
                                  │     (Guide Tone Lead Synth)   │
                                  │   ADSR: 80ms Attack / 150ms Rel │
                                  └───────────────────────────────┘
```

### Key Technical Considerations
* **Web Audio Autoplay Restrictions:** Audio Context unlocking is handled explicitly on the initial user interaction (`Tone.start()`).
* **ADSR Smoothing:** Soft attack ($0.08\text{s}$) and release ($0.15\text{s}$) prevent digital audio clicks on mobile speaker drivers.
* **Sinus Nitric Oxide (NO) Resonance Zone:** $130\text{ Hz} - 150\text{ Hz}$ ($C_3 - D_3$) is explicitly highlighted as the physiological peak target for sinus ventilation and NO boost.

## 3. Data Schema & State Management

```typescript
export type SessionState = 'idle' | 'inhale' | 'humming' | 'resting';

export type BreathModeId = 'vagal' | 'focus' | 'sinus_no' | 'custom';

export interface BreathMode {
  id: BreathModeId;
  name: string;
  description: string;
  inhaleSec: number;
  humSec: number;
  restSec: number;
  silentRestSec?: number; // Used for Sinus NO Recharge baseline recovery
}

export interface SequencePool {
  id: string;
  name: string;
  description: string;
  intervalOffsets: number[]; // Relative semitones from root e.g. [0, 1, 0, -1, 0]
  intervalDegrees: string[]; // e.g. ["1", "b2", "1", "b3", "1"]
}

export interface AppState {
  rootNote: string;         // e.g., "C3"
  octave: number;           // e.g., 3
  droneVolume: number;      // -60 to 0 dB
  guideVolume: number;      // -60 to 0 dB
  isDroneMuted: boolean;
  isGuideMuted: boolean;
  tempoBpm: number;          // 45 - 60 BPM
  selectedBreathMode: BreathModeId;
  inhaleSec: number;
  humSec: number;
  restSec: number;
  sessionState: SessionState;
  activeNote: string | null;
  activeDegree: string | null;
  selectedPoolId: string;
}
```

## 5. UI Layout & Component Decomposition

1. **Header & Timer Bar:** App title, session elapsed timer, screen wake-lock status.
2. **Breath Visualizer Pacer (`BreathRing`):** Animated 60 FPS Framer Motion radial visualizer.
3. **Pitch & Degree Display:** Real-time note badge ($G_3$) and degree indicator ($5$).
4. **Interactive Piano Keyboard (`PianoKeyboard`):** 17 touch-optimized keys ($C_2 - E_4$) with fundamental root marker dot and glowing active pitch indicator.
5. **Pitch & Calibration Bar (`PitchPicker`):** Fundamental root selector highlighting peak NO resonance range ($130-150\text{ Hz}$).
6. **Sequence & Breath Mode Selectors (`SequenceSelector`):** Quick preset pills for breath modes and interval sequences.
7. **Audio Controls Panel (`AudioControls`):** Primary Start/Pause button, drone/guide volume sliders, and mute toggles.
