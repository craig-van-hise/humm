# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The Humm application currently suffers from a ~200ms desynchronization between the 60 FPS Framer Motion `BreathRing` visualizer and the Tone.js audio playback during the `humming` phase. Additionally, the fundamental pitch selection interface is redundant and disorienting. It relies on both a dynamic `PianoKeyboard` (which shifts its key layout continuously) and a `PitchPicker` card. 

**Objectives:**
1.  **Resolve Audio/Visual Desync:** Refactor `useAudioEngine.ts` to execute synchronous audio scheduling, eliminating `await` micro-task delays in the playback loop.
2.  **Consolidate Pitch UI:** Deprecate the `PitchPicker` component entirely and route all root note selection through a singular, static-layout `PianoKeyboard`.
3.  **Static Keyboard Architecture:** Re-architect `PianoKeyboard` to render a fixed 2-octave layout (C to B) based on the current active octave, updating only the active key highlight and shifting the base layout only when an explicit "Octave" switch is toggled.

## 2. Technical Decisions & Dependencies
*   **Audio Scheduling:** The `playGuidePitch` function must become completely synchronous. Engine initialization and AudioContext unlocking are already handled during the `ready -> inhale` transition via `handleToggleSession`. Repeatedly awaiting context inside the rapid `playGuidePitch` interval causes the 200ms event loop delay. Explicitly scheduling with `Tone.now()` is required.
*   **Static Keyboard Logic:** The `PianoKeyboard` will generate a fixed array of 24 keys (2 octaves) starting from the octave integer extracted from the current `rootNote`.
*   **UI Merging:** The critical features from `PitchPicker` (Frequency display in Hz, Octave +/- controls, and the Peak Sinus Resonance badge) will be integrated directly into the header space of the new `PianoKeyboard`.

        ```typescript
        const NOTES = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'];
        const generateStaticKeys = (root: string) => {
          const match = root.match(/^([A-G]#?)(-?\d+)$/);
          const baseOctave = match ? parseInt(match[2], 10) : 3;
          const keys = [];
          for (let i = 0; i < 2; i++) { // 2 Octaves
            const oct = baseOctave + i;
            for (let note of NOTES) {
              keys.push(`${note}${oct}`);
            }
          }
          return { keys, baseOctave };
        };
        ```
